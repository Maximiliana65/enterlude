# Enterlude 개인정보처리방침

최종 수정일: 2026년 7월 27일

[日本語](./privacy.md) | [English](./privacy.en.md) | 한국어

## 데이터 수집에 대하여

Enterlude는 개인정보를 수집·저장·전송하지 않습니다. 대화 내용이나 입력 중인 텍스트를 읽거나 외부로 전송하는 일도 전혀 없습니다.

## 저장되는 정보

다음 설정 값만 Chrome Storage API(`chrome.storage.sync`)를 사용하여 브라우저 내부에 저장됩니다.

- 재미 기능의 켜짐/꺼짐 여부
- 재미 코멘트의 표시 언어 설정

이 값들은 사용자의 기기·브라우저 안에서만 유지되며, Enterlude 개발자를 포함해 그 어디로도 전송되지 않습니다.

## 작동 방식

Enterlude는 지원되는 AI 채팅 서비스(Claude / ChatGPT / Gemini) 화면에서 입력창·전송 버튼·재시도 버튼을 감지하여 오발송 방지 기능을 제공합니다. 대화 내용을 읽거나 기록하기 위한 목적이 아닙니다.

## 권한에 대하여

Enterlude는 지원되는 AI 채팅 페이지에서 오발송 방지 기능을 제공하는 데 필요한 범위 내에서만 작동합니다. 요청하는 권한은 설정 저장을 위한 `storage`와, 지원되는 3개 사이트로 한정된 열람 권한뿐입니다.

## 제3자 서비스

외부 서버와의 통신, 분석 도구(Google Analytics 등), 광고 표시, 추적(트래킹)은 전혀 하지 않습니다.

## 요금 안내

Enterlude는 무료입니다. 광고, 유료 기능, 구독은 없습니다.
