## ChatGPT公式Enter設定との併用

- [ ] 公式設定「Enter送信OFF」＋Enterludeロック中: Enterは改行、送信ボタンはロック
- [ ] 公式設定「Enter送信OFF」＋Enterlude解除中: Enterは改行、解除維持、コメントなし
- [ ] 上記の解除維持中に送信ボタンを押す: 送信、再ロック、コメント表示
- [ ] 公式設定「Enter送信ON」＋Enterludeロック中: Enterは改行、送信ボタンはロック
- [ ] 公式設定「Enter送信ON」＋Enterlude解除中: Enterは送信、再ロック、コメント表示
- [ ] 公式設定ON / OFFの両方で、IME、Shift+Enter、Esc、再試行、`Ctrl+Shift+U`が従来どおり
