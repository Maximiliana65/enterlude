# Enterlude

AIチャット(Claude / ChatGPT / Gemini)で、うっかりEnterキーや送信ボタンで
書きかけのメッセージを送ってしまう事故を防ぐ、Chrome/Edge拡張機能です。

Enterlude is a Chrome/Edge extension that prevents accidental sends in AI chats
(Claude / ChatGPT / Gemini).

Enterlude는 AI 채팅(Claude / ChatGPT / Gemini)에서 실수로 메시지가 전송되는
사고를 막아주는 Chrome/Edge 확장 프로그램입니다.
