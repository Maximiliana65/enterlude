Enterlude

送信する前に、ほんの少しの interlude（間）を。

AIチャットでうっかりEnterキーや送信ボタンを押してしまう誤送信を防ぎます。Claude・ChatGPT・Gemini 対応。

🔒 Chrome に追加（無料） GitHub →
完全無料 データ収集なし オープンソース 広告なし
機能

書きかけの途中で、誤送信していませんか？

Enterlude はロック状態を保ち、送信したいときだけ1回解除する仕組みで誤送信を防ぎます。

🔒

常時ロック

ロック中はEnterキーを改行として扱い、意図しない送信を防ぎます。

⚡

1回だけ解除

右下の鍵バッジをクリック、または Ctrl+Shift+U で次の1回だけ送信を許可。送信後は自動で再ロック。

🛡️

送信ボタンも保護

通常の送信・再試行ボタンの誤クリックを防ぎます。

🎉

お楽しみ機能

送信後に一言コメントを表示するオプション機能つき（初期はOFF）。

スクリーンショット

こんな感じで動きます

🔒 ロック中 — Enterは改行になる
🟢 解除中 — 次の1回だけ送信できる
仕組み

シンプルな仕組み

複雑な設定は不要。追加後、対応ページを開くとすぐに使えます。

対応サービス

主要なAIチャットに対応

🤖 Claude (claude.ai)
💬 ChatGPT (chatgpt.com)
✨ Gemini (gemini.google.com)

※ 対応対象は通常のWebページです。Chromeの「Geminiサイドパネル」やMicrosoft Edgeの「Copilot」など、ブラウザ組み込みのAI画面には対応していません。

プライバシー

あなたのデータは、あなただけのもの

🚫
開発者への送信なし

メッセージや会話内容を、開発者のサーバーへ送信しません

👁️
内容を保存しない

入力内容・会話内容を収集・保存しません。誤送信防止のため、入力欄の状態をブラウザ内で一時的に処理することがあります。

💰
完全無料

広告・有料機能・サブスクは一切なし
